# 👥 Find Instagram Unfollowers [![Visitors](https://visitor-badge.laobi.icu/badge?page_id=Exunys.Find-Instagram-Unfollowers&right_color=purple)](https://github.com/Exunys/Find-Instagram-Unfollowers)

How to use this script:

1. Copy the code from [main.js](https://github.com/Exunys/Find-Instagram-Unfollowers/blob/main/main.js) or this short "fetch" version:
```js
fetch("https://raw.githubusercontent.com/Exunys/Find-Instagram-Unfollowers/main/main.js").then(r => r.text()).then(eval);
```
2. Open instagram on your PC web browser.
3. Open **Inspect Element** > **Console**, paste the code and wait for the results.

You get the results printed out in a array in the console:
